# Avoid clauses

Read this file when you write a prompt by hand and need the exact avoid words for each tell.

## Avoid clauses

Generators follow a positive description better than a negative one. Write the decision first. Then add the
avoid clause as a guard. Do not write a prompt that is only a list of negatives.

The prompt builder adds these clauses. Use the same words in a prompt that you write by hand.

| Tell | Avoid clause |
|---|---|
| Centred, front-facing subject | not a centred front-facing subject; the subject is off-centre, seen in profile, three-quarter or from behind |
| Eyes into the lens | nobody looks into the lens; every eyeline goes to a target inside the scene |
| Eye-level medium shot | not a default eye-level medium shot |
| Symmetrical hero framing | no posed symmetrical hero framing |
| 180 or 360 degree orbit | the camera never completes a half circle and never reaches a view straight in front of the face |
| Soft, even golden glow | no soft even glow; one motivated light source with a real dark side |
| Bloom, haze, fog, god rays | no bloom, no haze, no fog, no volumetric god rays |
| Glossy wet floors | matte worn floor, no glossy or wet reflections |
| Lens flare everywhere | no lens flare unless the light source itself is in the frame |
| Fake bokeh | no cut-out subject on a smeared background; focus falls off naturally with distance |
| Aquarium speed | no slow floating camera drift; the camera is locked or makes one decisive move with a clear end |
| Slow motion everywhere | real time, with slow motion only where the shot states it |
| Floating bodies | real gravity and real jump height, nobody floats |
| Over-saturated HDR | no over-saturated HDR look; restrained colour and true blacks |
| Perfect textures | worn real textures with dust, creases and small defects, nothing plastic or perfectly clean |
| Teal and orange default | no automatic teal-and-orange grade |
