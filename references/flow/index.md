# The steps

Read the step that you do now. Each step is a child file. The steps are a map, not a checklist.

- [Listen and interpret](listen-interpret.md): Read when the user describes a shot: take the words, run `plan`.
- [Find the look: references](look-references.md): Read when `plan` prints `UNKNOWN REFERENCE` or `LOOK NOT CLEAR`.
- [Find the look: rounds and the lock](look-rounds-and-lock.md): Read when pictures must settle the look.
- [Mock stills](mock-stills.md): Read when you make the mock stills.
- [Blocking previs (optional)](../previs/index.md): Read when the camera path, the lens or the positions are the open question.
- [Present](present.md): Read when you show the options.
- [Pick, mix, change](choose.md): Read when the user picks, mixes or changes.
- [More than 1 shot (optional)](../sequences/index.md): Read when the user wants a fight, a hit, a chase or a small scene.
- [De-slop mode](deslop.md): Read when the user pastes a prompt, or says that a take looks fake or "AI".
